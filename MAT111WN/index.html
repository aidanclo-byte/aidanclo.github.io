ABSTRACT

This project is a website created to present an animated, interactive sketch with a storyline while demonstrating both sufficient application of technical skills in coding with JavaScript, HTML, and CSS, alongside creative human idea generation and execution.

The story centers around a child sent to the hospital after a boating accident, the decision that can be made before treatment, and the consequences of the player's decision.

The website was developed through a process that included collaborative idea generation with peers in the MAT111WN class, designing with peer feedback, coding in and outside of class, and testing outside of class.

The project used p5.js for the animated sketch, VS Code for creating the website format, and GitHub for hosting the website live.

The purpose of this website was to create an interactive, functional web narrative while strengthening my own understanding and experience with coding an interactive website.
